# UI-система

Статус: **каркас**. Есть главное меню и заглушки экранов выбора команды и составов. Визуальный язык
новой игры ещё не задан: текущая палитра — временная, из карьерного прототипа.

Функциональный объём меню и сверка с `of_port` — на странице [[функционал-меню]]. Здесь — как экран
устроен и какие правила взаимодействия нельзя ломать.

## Экраны

| Экран | Статус | Задача |
|---|---|---|
| Главное меню | каркас | Крупный вертикальный список: «Играть», «Составы», «Настройки» |
| Выбор команды | заглушка | Страна → лига → клуб; крупный центральный объект + панель деталей |
| Составы | заглушка | Поле со слотами, фокус игрока, запас/резерв, обмен A/B |

Заглушки уже показывают количества канона из `/api/meta`, чтобы проверять связь с сервером.

## Правила

- **Визуальный язык — собственный, не из `of_port` и не из карьерного прототипа.** Зелёно-лаймовая
  палитра `gf-career-prototype` — только временный каркас. Макеты новой игры задают внешний вид;
  карьерный Figma (`https://www.figma.com/design/sFScRV2E8CycOIf6qW2WQf/Untitled`) — референс
  компоновки и взаимодействий, не визуальной правды.
- **Один фокус на экран.** На экране ровно один `[data-nav]:focus`; остальное — контекст.
- **Hover = selected.** Наведение мыши переводит тот же фокус, отдельного hover-состояния нет.
  Визуальные состояния — `default`, `selected`, `disabled`.
- **Меню — верхние табы**, переключение `L1`/`R1`; нижняя легенда показывает подсказки последнего
  устройства (`Enter`/`Esc`/стрелки или `A`/`B`/`L1`/`R1`).
- **Скролл только внутри списков и виджетов.** `.screen` не скроллится.
- **Никаких россыпей мелких кнопок.** Действия — крупные вертикальные элементы.
- **Стиль — диванно-телевизионный:** крупная типографика, тёмный «стадион», стеклянные панели,
  мягкое свечение фокуса.

## Текущая реализация

- `web/src/App.svelte` — состояние экрана (`menu`, `team-select`, `lineup`), загрузка `/api/meta`,
  `Esc` возвращает в меню, нижняя легенда.
- `web/src/lib/MainMenu.svelte` — вертикальные кнопки, `data-autofocus` на первой.
- `web/src/lib/TeamSelect.svelte`, `Lineup.svelte` — панели-заглушки с фактами канона.
- `web/src/lib/Controls.svelte` — нижняя легенда (пока только клавиатура).
- `web/src/app.css` — временные токены палитры из карьерного прототипа и стили каркаса.

## Что дальше

2. Собрать выбор команды: страна → лига → клуб, фокус и панель деталей.
3. Собрать экран состава: слоты 4-3-3, карточки игроков, запас/резерв, обмен.
4. Подключить геймпад: перенести `input.js`/`actions.js` и легенду последнего устройства.
5. Зафиксировать решения в этой странице, чтобы переносить их в Godot.
