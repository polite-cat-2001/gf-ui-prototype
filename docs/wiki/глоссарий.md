# Глоссарий

Имена предметной области проекта. Термин берётся отсюда для заголовков задач, имён тестов и
формулировок гипотез. Разрешил новый термин — допиши сюда.

| Термин | Определение |
|---|---|
| UI-прототип | Веб-песочница меню новой футбольной игры для переноса решений в Godot |
| Функциональный эталон | `GameplayFootball-of_port`, ветка `of_port`: набор меню-сценариев, которые прототип должен повторить |
| Визуальный язык | Собственная графика, типографика и компоновка новой игры; не копируется из `of_port` или карьерного прототипа |
| Канон | Read-only данные мира: страны, лиги, клубы, игроки, формы. Собирается в `canon.db` |
| Клуб | Команда из канона; в UI — эмблема, цвета, стадион, состав и формы |
| Игрок | Запись канона с амплуа, OVR, потенциалом и набором статов |
| Состав | Набор игроков клуба, разложенный по слотам схемы |
| Стартовый XI | Одиннадцать игроков, выходящих с первых минут |
| Капитан | Игрок с повязкой; в хабе пока лучший OVR стартового XI |
| Предматчевый хаб | Шаговый экран после выбора формы: мета матча, клубы, стартовые XI и действия перед выходом на поле |
| Слот | Позиция на поле в схеме: амплуа, координаты `x/y` и игрок |
| Схема | Расстановка слотов, например 4-3-3 |
| Запас | До семи игроков в заявке, которые могут выйти на замену |
| Резерв | Игроки ниже заявки; в матч не попадают |
| Форма (kit) | Набор PNG клуба: `main`, `white`, `black`, `reserve`, `gk1`, `gk2` |
| Фокус | Единственный выбранный элемент экрана; управляется D-pad, стрелками или мышью |
| Selected | Визуальное состояние фокуса; отдельного hover-состояния нет |
| Устройство ввода | Геймпад или клавиатура; нижняя легенда показывает подсказки последнего |
| Экран | Одна композиция UI: меню, выбор команды, формы, предматчевый хаб |
| OVR | Показываемая сила игрока 0–99 из `ratings_output.json` |
| Потенциал (pot) | Жёсткий потолок OVR |
