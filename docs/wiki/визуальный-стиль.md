# Визуальный стиль

Статус: **зафиксирован**. Решение принято 2026-10-30. Референс механики — меню FIFA 18; визуальный
язык собственный, но построен на тех же принципах «печатной страницы на стекле».

Страница отвечает на вопрос «как выглядит». Как устроены экраны и фокус — [[ui-система]]. Объём
меню — [[функционал-меню]].

## Решение

| Вопрос | Выбор |
|---|---|
| Основа | **Светлая**, как в FIFA 18: почти белые плитки на размытом стадионе |
| Выбор | **Полная инверсия заливки**: светлая плитка → тёмно-индиго с лаймовым заголовком |
| Фон | Размытый кадр стадиона с медленным зумом/паном |
| Палитра | **Два акцента с разными ролями**: магента — служебный, лайм — только «ты сейчас здесь» |
| Форма | Острые углы, плотные швы, без бордеров и скруглений |
| Типографика | Узкий капсовый гротеск (Barlow Condensed) для заголовков |
| Композиция | Бенто: один крупный тайл + компактные |

## Формула

ТВ-интерфейс для геймпада. Светлые плитки лежат на движущемся приглушённом стадионе и образуют одну
плиту, разделённую узкими швами. Ровно один элемент всегда выбран, и выбор — это переворот заливки,
а не подсветка. Магента отмечает «сюда можно нажать», лайм — «ты сейчас здесь». Крупный капсовый
заголовок сверху-слева, арт или глиф снизу-справа, хром по краям safe area, контекстная легенда
внизу-слева.

## Слои

1. **Стадион** — фото без размытия, `saturate(.85)`, `brightness(.82)`, медленный зум 1.0 → 1.07 за 42с.
   Читается как настоящий кадр трансляции; гасится только скримом и десатурацией.
2. **Скрим** — градиент сверху (тёмно-синий → прозрачный) и вигнетка по краям. Нужен, чтобы белые
   плитки не сливались с небом.
3. **Панель** — сетка тайлов на полупрозрачных светлых заливках.
4. **Хром** — табы, легенда, бренд, уведомления. Никогда не перекрывает сетку.

## Сетка

- 4 колонки, `gap: 10px`, `border-radius: 0`, бордеров нет.
- Один тайл в разделе — крупный (`2×2`), остальные — `1×1` или `2×1`.
- Панель и полоса табов выровнены по одному левому краю и одной ширине: табы — шапка панели, не
  отдельная навигация.
- Зазоры прозрачные — сквозь них видно стадион. Разделяет заливка, а не линия.
- Верхняя строка выше нижней, но внутри строки высота одинаковая.

## Анатомия тайла

```
┌─────────────────────────────┐
│ ЗАГОЛОВОК                   │  ← top-left, капс, 2 строки максимум
│ подпись                     │  ← опционально, обычный регистр
│                             │
│                    [глиф]   │  ← bottom-right, плоский, один цвет
└─────────────────────────────┘
```

- Внутренний padding — 24px, одинаковый во всех тайлах.
- Текст никогда не центрируется и не прилипает к краю.
- Арт либо заливает правую половину/весь тайл (bleed в край, со скримом под текст), либо его нет, и
  тогда работает крупный глиф.
- Абзац описания — только на крупном (выбранном) тайле.
- Цвет глифа: на светлой плите — чернильный, на выбранной — магента. Лайм остаётся только за
  заголовком, чтобы акценты не спорили.
- Точки пагинации — только если у слота реально несколько содержимых.

## Состояния

| Состояние | Вид |
|---|---|
| `default` | Заливка `--tile`, текст `--ink`, магентовая рейка 6px слева |
| `selected` | Заливка `--focus-fill`, текст `--focus-ink`, заголовок `--focus-mark`, глиф `--rail`; рейка исчезает |
| `disabled` | `opacity: .42`, без рейки и без реакции на ввод |

- Состояния только три. `hover` не существует: мышь переводит тот же `selected`.
- **Выбранная плитка приподнимается:** `scale: 1.008` и сдвиг на 6px наружу — по горизонтали в
  сторону своего края, по вертикали вверх для верхнего ряда и вниз для нижнего. Это отдельный от
  заливки сигнал «плитка вынута из сетки»; работает только вместе с инверсией.
- Зазор между табами и сеткой — 10px, чтобы подъём не упирался в полосу табов.
- Фокус — один глобальный курсор. Он может стоять на табе; тогда ни один тайл не выбран.
- Контраст состояний держится на светлоте, а не на цвете: читается при дальтонизме и с дивана.

## Типографика

- Заголовки — Barlow Condensed, 700–800, `text-transform: uppercase`, трекинг `-0.01em`.
- Текст — Inter, 400–600.
- Никаких засечек, курсива и декоративных шрифтов.

| Роль | Размер (1920) | Начертание |
|---|---|---|
| Таб | 24 | 700, капс |
| Заголовок тайла | 52 | 700, капс |
| Заголовок крупного тайла | 64 | 800, капс |
| Подпись тайла | 20 | 500 |
| Мета (лига, соперник) | 17 | 500 |
| Легенда кнопок | 16 | 500 |
| Бренд | 30 | 800, капс |

Ничего мельче 16px — это 10-foot UI. Иерархия задаётся размером и весом, не цветом.

## Токены

```css
:root {
  /* поверхность */
  --tile: rgba(244, 246, 249, 0.94);
  --tile-soft: rgba(255, 255, 255, 0.55);
  --focus-fill: #171b3f;

  /* текст */
  --ink: #1d2138;
  --ink-2: #5a5f78;
  --focus-ink: #f6f8fb;

  /* акценты */
  --rail: #e6236e;        /* служебный: рейки, подчёркивание активного таба */
  --focus-mark: #c9f227;  /* только заголовок выбранного */

  /* геометрия */
  --gap: 10px;
  --pad-tile: 24px;
  --pad-safe: 48px;
  --radius: 0;

  /* типографика */
  --font-heading: 'Barlow Condensed', sans-serif;
  --font-body: 'Inter', sans-serif;
}
```

Правило палитры: **магента не заливает, лайм не украшает.** Магента — только линии и полоски.
Лайм — только текст выбранного элемента. Всё остальное — светлое или тёмно-индиго.

## Анимация

- **Табы.** Белая плашка активного таба — отдельный слой, который скользит между позициями:
  `transform` + `width`, 280ms, `cubic-bezier(.2,.72,.2,1)`. Текст табов меняет цвет 220ms.
- **Фокус на табах.** Когда курсор уходит с плиток на полосу табов, активный таб инвертируется:
  тёмно-индиго, лаймовый текст и лаймовая линия вместо магентовой — тот же приём, что у плитки.
  Возврат в сетку снимает инверсию. Тайлы при этом не показывают выделения.
- **Смена таба.** Плитки новой сетки въезжают с той стороны, куда ушёл таб (знак зависит от
  направления): сдвиг 64px + проявление, 380ms, каскад по 28ms на плитку.
- **Выход за край сетки.** Стрелка вбок с крайней плитки переключает на соседний раздел тем же
  въездом и ставит фокус на плитку у противоположного края той же строки.
- **Выбор.** Инверсия мгновенная, подъём — 180ms тем же изингом, что и табы.
- Анимации играют только на смену состояния, никогда на загрузку экрана или возврат из подменю.

## Хром

Пять фиксированных зон, одинаковых на всех экранах:

| Зона | Что там |
|---|---|
| Верх-центр | Табы, ширина панели. Активный — белая плашка + магентовая линия; сфокусированный — тёмно-индиго + лаймовый текст и линия |
| Центр | Сетка тайлов, единственное место для контента |
| Под сеткой, слева | Легенда кнопок: по левому краю панели, сразу под нижним тайлом |
| Низ-право экрана | Логотип/бренд |
| Верх-право | Системные уведомления (баннер со скошенным краем) |

Углы не занимает контент. Safe area — 44px по бокам.

- Легенда привязана к сетке, а не к краю экрана: она входит в тот же блок и выравнивается по его
  левой границе.
- Блок «табы + сетка + легенда» центрируется по вертикали во всём экране; бренд и уведомления живут
  абсолютным слоем поверх фона.
- Высота сетки одинаковая на всех табах (`clamp(420px, 58vh, 660px)`). Разделы настроек занимают ту
  же площадь крупными плитками `2×2`, а не мелкими в один ряд.

## Фон

- Ассет — `web/public/stadium.jpg` (2560px, ~690 КБ), сжатая копия исходного кадра; сам исходник не
  правится, вся обработка в CSS.
- Одно фото стадиона на всё приложение: сцена стабильна, меняется только панель.
- Фон **не размывается**: стадион остаётся узнаваемым кадром, а не цветным пятном. Читаемость
  плиток обеспечивают скрим, десатурация и непрозрачная заливка тайлов, а не blur.
- Движение — медленный зум/пан, не быстрее 30 секунд на цикл; при `prefers-reduced-motion` выключен.

## Что не копируем из FIFA 18

- Фотоколлаж в каждом тайле — для прототипа достаточно глифа и эмблемы клуба.
- Карусели внутри тайла — одно содержимое на слот, пока не понадобится обратное.
- Оранжевый как токен: в референсе он живёт только в артах.
- Пустой сегмент полосы табов.

## Перенос в Godot

- Токены выше — единственный источник значений; в Godot они становятся `Theme` и константами.
- Сетка — `GridContainer` с `h_separation/v_separation = 10`; крупный тайл — через `GridContainer`
  с растянутыми ячейками или ручной раскладкой.
- Инверсия — не анимация цвета, а смена двух `StyleBoxFlat` (default/selected) на `Panel`.
- Прозрачность тайла при переносе на 3D заменяется на непрозрачную заливку: дешёвле и не зависит
  от фона.
